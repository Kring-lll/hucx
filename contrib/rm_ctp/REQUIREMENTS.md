# RM DATA PSN精简实验副本需求清单

分支：`rm-um-send-nopsn-dev`。完整RM保留在`rm-um-send-dev`，本分支不继承其验收状态。
目的：保持UM建链、窗口与ACK框架，测量去掉线上DATA PSN及接收判定后的正常路径性能差异。

| 编号 | 需求 | 实现/验收边界 |
|---|---|---|
| N1 | 独立分支、Windows worktree、节点构建与安装 | 不移动完整RM分支、不覆盖a4d安装；节点待验 |
| N2 | DATA头8B→6B，不携带DATA PSN | 保留packet_type和ack_psn；本地窗口键仍存在；真实节点线上观察待验 |
| N3 | 正常DATA跳过逐包PSN保序/去重判断 | 假设按序且不重不丢，不能宣称同等可靠性 |
| N4 | 保留UM建链、ACK、窗口与缓冲生命周期 | ACK和建链头8B；选中DATA重传时停止样本，建链重试保留 |
| N5 | 接收偏移/对齐、异步回调和延迟释放正确 | 本地真实EP路径ASan/UBSan测试；ARM待验 |
| N6 | 复用UCP分片，单次SEND≤4096，inline保持 | 原AM能力不扩大，防止同时改变UCP选路；节点待验 |
| N7 | 原版OSU完整RM/副本同批性能资源对照 | RX4096，五轮轮换，全部样本与异常保留；节点待验 |
| N8 | 对等构建隔离、数据校验和明确能力限制 | 地址格式标记，legacy地址导入前拒绝；节点待验 |
| N9 | READ/WRITE、硬件故障、完整C/D | 不在本轮；不宣称通过 |

- [ ] 新副本ARM隔离构建、双端模块与库maps通过。
- [ ] 所选尺寸/边界、大小交替与多进程集合正确性通过。
- [ ] 双端真实DATA头6B、完整RM头8B及SEND上限观察通过。
- [ ] 同批215项及14组性能/资源结果完成并审阅。
